# Web Development 1 - Midterm Project
The midterm project for this class involves taking the wireframes we have created for our final intergrated projects (ZIMA Beverage Rebrand) and turning that into a HTML page with bozed content. The goal of the assignment is not to finish the page completely, but set the layout and structure for the page using box's and the CSS grid that has been previously created.
## Installation
No installation required. Simply download the zip file and extract.

## Usage
Open index.html in the browser of your choice.
